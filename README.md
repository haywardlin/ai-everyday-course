# AI生活与工作入门

面向零基础学习者的23页互动教学课件，不依赖特定职业或公司背景。

在线访问：https://haywardlin.github.io/ai-everyday-course/

## 课程内容

- AI在表达、阅读、比较、准备和学习中的具体用途。
- 目标、背景、材料、要求和输出格式组成的提问方法。
- 消息改写、通知整理、商品比较、旅行准备和英语练习。
- 事实核查、隐私保护、人工确认和完整效率测算。
- 互动练习、可复制提示词及七天实践安排。

## 使用方法

浏览器访问在线地址，或下载 `index.html` 后直接打开。
使用页脚按钮或键盘左右方向键翻页；支持目录、讲者备注、连续阅读、提示词下载和打印。
建议讲授30分钟，另留10分钟练习。案例与测算均为教学示例，不代表实测收益。

## 数据说明

课件不连接AI接口，不上传或保存练习输入，不配置第三方统计。
页面由GitHub Pages托管；访问请求由托管服务处理。研究资料链接会打开外部网站。
提示词生成器只在浏览器内拼接文本，不生成AI回答。
