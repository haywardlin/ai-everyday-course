# AI直播电商实操课

面向零基础直播运营、主播、场控和客服的47页互动教学课件。通过一个49元折叠收纳箱的虚构案例，学习如何把AI用于直播前、中、后的具体工作。

在线访问：https://haywardlin.github.io/ai-everyday-course/

## 课程内容

- 商品事实卡：原始资料、完整提问、参考结果和核对方法。
- 选品取舍、单笔贡献与简化投放空间计算器。
- 评论分类、卖点、90秒直播脚本和30秒短视频分镜。
- 商品图审核、FAQ、主播陪练、开播检查和场控分流。
- 直播漏斗、退款观察、费用核算、复盘及单变量测试。
- 10组可复制提示词、5份CSV练习表、20分钟作业和互动自测。

## 使用方法

浏览器访问在线地址，或下载 `index.html` 后直接打开。
使用页脚按钮或键盘左右方向键翻页；支持目录、讲者备注、连续阅读、提示词下载和打印。
建议分两次讲授，第一课60分钟、第二课45分钟，另留20分钟实操。每页包含讲者备注。
商品、评论、价格、成本和场次数据均为虚构练习，不代表真实商品或经营收益。

## 数据说明

课件不连接AI接口，不上传或保存练习输入，不配置第三方统计。
页面由GitHub Pages托管；访问请求由托管服务处理。研究资料链接会打开外部网站。
提示词生成器只在浏览器内拼接文本，不生成AI回答。计算器按明确的课堂假设计算，不替代真实账单、合规审核或投资决策。
课件未连接任何直播平台、广告账户或订单系统。
